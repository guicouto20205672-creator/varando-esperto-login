# Varando do Esperto — Login

Tela de login responsiva com suporte a autenticação Supabase.

## Arquivos
- index.html — interface para celular e computador
- app.js — login e recuperação de senha
- fundo-varando.png — imagem de fundo (adicione a imagem enviada com este nome na raiz do repositório)

## Configuração
1. Crie/abra um projeto no Supabase.
2. Em Project Settings > API, copie a Project URL e a chave pública anon/publishable.
3. Edite app.js e substitua os dois valores COLE_...
4. Em Authentication > Providers, habilite Email e crie usuários em Authentication > Users.
5. Ative GitHub Pages em Settings > Pages (branch main, root).

Nunca coloque a service_role key no navegador. O painel pós-login ainda precisa ser conectado.
